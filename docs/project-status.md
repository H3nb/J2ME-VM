## Implemented on main

- **G1 structural class-file reader:** bounded CLDC-era class-file parsing, not a bytecode verifier ([PR #1](https://github.com/H3nb/J2ME-VM/pull/1)).
- **Partial G2 execution proof:** validated limited integer opcodes, locals, branches and stepping; nested/recursive **same-class** `invokestatic`, descriptor-aware lookup and VM-owned frames ([PR #3](https://github.com/H3nb/J2ME-VM/pull/3), [#16](https://github.com/H3nb/J2ME-VM/pull/16), [#23](https://github.com/H3nb/J2ME-VM/pull/23)). [PR #29](https://github.com/H3nb/J2ME-VM/pull/29) bounded repeated method lookup work.
- **Original fixtures and bounded research:** independently authored test inputs and provenance ([PR #11](https://github.com/H3nb/J2ME-VM/pull/11), [#20](https://github.com/H3nb/J2ME-VM/pull/20)); reference/exception prerequisites remain *research*, not executable support ([PR #31](https://github.com/H3nb/J2ME-VM/pull/31)).
- **WP05 concurrency contract:** a **proposal only**, referencing separate unpublished local experiments, with no concurrent runtime implementation on public `main` ([PR #34](https://github.com/H3nb/J2ME-VM/pull/34), [contract](wp05-concurrency-contract.md)).

The last examined [post-merge main CI](https://github.com/H3nb/J2ME-VM/actions/runs/41001530506) passed for `dad35bfc`. CI supports only the exercised Rust proof, not Java ME conformance.
